# 日报 Prompt 优化方案（写作规范对齐）

- 日期：2026-09-16
- 范围：`src/ai_analyzer.py` 全部 6 个 prompt + 调用工程
- 依据：新闻写作行业规范（倒金字塔、5W1H、AP News Values 正文规范）+ 我们的线上数据
- 目标：让 AI 写作从"模板化四段式"转向"新闻导语优先、事实可归因、长度克制"

---

## 一、新闻写作规范研究结论

### 1.1 倒金字塔（行业标准结构）

来源：中文维基「倒金字塔结构」+ 路透肯尼迪遇刺名篇范例

```
最重要的事实 → 次重要细节 → 一般背景 → 次要信息
（导语把最精彩内容放最前端；主体按重要性递减）
```

三条硬特征（引自新闻学大辞典/维基）：

| # | 特征 | 说明 |
|---|---|---|
| 1 | 最重要的写在前面 | 按重要性依次递减排列 |
| 2 | **一段只写一个事实** | 禁止一段堆多个信息点 |
| 3 | **全部陈述事实，记者不发议论** | 不写评论、不写推断、不做总结 |

优点（对 AI 写作同样成立）：可快编快删——删掉末尾段落不影响全文；读者随时可停。

> 路透范例： "肯尼迪总统今天在这里遭到刺客枪击身亡。／总统与夫人同乘一辆车中，刺客开3枪，命中总统头部。／总统被送往医院，经大量输血，不久后身亡。／官方消息称，总统下午1点逝世。／副总统约翰逊将继任总统。"
> 注意：每句一个事实，全部陈述句，无一句评论。

### 1.2 5W1H（六何法）

何人（Who）、何事（What）、何时（When）、何地（Where）、为何（Why）、如何（How）。
→ 导语应尽量回答 **What+Who+When**；后文补 Where/Why/How。

### 1.3 AP 正文规范（对 AI 最有约束力的四条）

| 规范 | 要求 | 对我们的映射 |
|---|---|---|
| 归因（Attribution） | 任何可被质疑的内容必须归因；给出信源全名与可信度依据 | 我们已有"可归因句式"，但未强制"争议内容必须归因" |
| 引语（Quotes） | 不得改动引语；翻译必须忠实；不得断章取义 | 翻译 prompt 需加"不得改变语气强度"（may≠将） |
| 他人材料（Use of Others' Material） | 不得照搬；必须改写；新闻稿不得原样发布，须核实+补充 | 我们的"媒体转述必须归因"符合；可再强化"不得整句搬运" |
| 更正（Corrections） | 错了立刻明确更正，不得用委婉语 | 我们无更正机制（P2 可做"更正说明"字段） |

### 1.4 中文新闻习惯（补充）

- 首句即导语，日期常置句首："9 月 16 日，……"
- 数字规范：万/亿、百分比、币种（美元/人民币）统一；不混用阿拉伯与汉字
- 称谓规范：首次全称+职务（"美国总统特朗普"），后文简称（"特朗普"）；机构首次全称
- 一段一义；短段落

## 二、逐个 Prompt 差距分析

### 2.1 SCORE_PROMPT（评分，:354）

| 现状 | 差距 | 风险 |
|---|---|---|
| 分档 90+ 要求"官方首发" | 与"新闻价值"维度冲突：官方≠高价值（我们后来用 newsworthiness 部分修正） | 分档仍偏向官方稿 |
| newsworthiness 单维 0-1 | 新闻价值是多维的（影响面/显著性/时效/新奇性/冲突性） | 一维难解释、难校准 |
| 无 few-shot | 模型对"例行公告"和"重大诉讼"的区分靠 instruction | 边界案例不稳定 |
| summary 50 字内无要素要求 | 未要求 who+what 先行 | 摘要质量参差 |
| 无"信息不足"惩罚 | 材料少的事件可能与材料全的同分 | 弱报道占位 |

### 2.2 COLUMN_DIGEST（写作，:898）——差距最大

| 规范要求 | 现状 | 差距 |
|---|---|---|
| 倒金字塔：最重要在前、逐段递减 | "事实→变化→后果"四段式 | 是"分析文"结构，不是"新闻"结构；"变化/后果"两句天然滑向议论 |
| 一段一事实 | 要求"写成一段连贯叙述" | 明确违背（一条 body 塞 2-4 个信息点） |
| 不发议论 | 有禁止词表，但"接下来影响谁"仍引导推断 | 观察到的"后续影响对象包括…"套话来源 |
| 导语 What+Who+When | 只要求"首句必须有日期" | 缺 What/Who 强制 |
| 5W1H 完备 | 无 checklist | 缺 Where/Why 时无处理规则 |
| 数字/称谓规范 | 无 | 数字混用、称谓不一致 |
| 抽象示例 | 有"抽象结构示例" | 已观察到模板化复制（句式趋同） |
| 自检 | 无 | 错误靠事后门禁发现 |

### 2.3 HEADLINE_TRANSLATION（翻译，:1023）

| 差距 | 说明 |
|---|---|
| 无术语表 | 人名/机构译名各批可能不一致（同一天多次调用） |
| 无长度上限 | 中文标题可超 30 字，列表观感差 |
| 无语气强度约束 | "may/considering"翻成"将/计划" 会升级事实 |
| 无数字格式要求 | 英文数字直译易不一致 |

### 2.4 DAILY_OVERVIEW（总览，:1173）

| 差距 | 说明 |
|---|---|
| 结构未对齐导语原则 | 120-180 字全篇总览可以，但应明确"最重要变化放最前" |
| 与正文重复 | 缺"更高抽象层、不重复正文句子"的度量 |

### 2.5 PERIODICAL_OVERVIEW（:1117）

周/月报暂停中，本轮只做同步性小改（术语对齐），不重构。

### 2.6 FALLBACK_BODY（兜底，:1446）

| 差距 | 说明 |
|---|---|
| 结构未对齐 | 现为"日期+概括+…"，应改为导语优先：最重要事实前置 |
| 与 digest 风格一致性 | 应共用同一套句式/称谓规范 |

## 三、优化方案（Prompt 层面）

### 3.1 SCORE_PROMPT 改造

**a. 把"新闻价值"拆成 5 个可校准的维度**（替代单维 newsworthiness）：

| 维度 | 取值 | 校准锚点 |
|---|---|---|
| `impact` | 0-1 | 1=制度性变化/战争/全国性影响；0.5=行业级；0.2=个案 |
| `prominence` | 0-1 | 1=总统/最高法院/央行级主体；0.5=部长/大公司；0.2=地方 |
| `timeliness` | 0-1 | 1=当日首发；0.5=当日跟进；0.2=旧事重提 |
| `novelty` | 0-1 | 1=首次披露；0.5=已知事实新进展；0.1=重复报道 |
| `conflict` | 0-1 | 1=明确对抗/诉讼/战争；0.3=政策分歧；0=无冲突 |

保留 `routine`（例行度）；`newsworthiness` 改为由以上五维**推导**（公式化：加权和，权重可配），避免模型随意打分。

**b. 分档规则重锚**：删掉"90+ 必须官方首发"（与价值冲突），改为：
```
90+：impact≥0.8 且 timeliness≥0.8 且 novel≥0.8（不管来源是否官方）
来源权重只作为 ±5 分修正，不作为 90+ 门槛
```

**c. 加"信息不足上限"**：
```
输入 content 少于 120 字符或缺少日期 → score 上限 69，is_hard_news=false
```

**d. 加 few-shot（2 正 2 负）**：正例=白宫行政令/最高法院裁决；负例=机构评论期公告/企业博客产品稿。
（注意：示例实体用虚构，避免污染）

**e. summary 要素化**：要求 `谁 + 做了什么 + （可选）关键数字`，禁止以"据报道"开头。

### 3.2 COLUMN_DIGEST 改造（核心）

**a. 结构改为"倒金字塔三句版"**：

```
第 1 句（导语）：What + Who + When——最重要的事实，日期置句首
第 2 句（细节）：关键数字/第二个事实（可含 Where/Why）
第 3 句（可归因影响）：只写输入材料里能确认的影响或后续；没有就省略
```

明确规则：
- **一段只写一个事实**（替代"连贯叙述"要求）
- **不发议论**：第 3 句只能写"材料给出的"影响；无材料时只写前两句（允许 2 句成品）
- 5W1H checklist：Who/What/When 必须齐；Where/Why/How 有则写
- 删除"抽象结构示例"（模板化来源），改为"反面示例"（展示被禁写法）

**b. 数字/称谓规范（新增段落）**：
```
数字：万/亿、百分比、货币单位统一；不写"约"当不确定时用"据报道为"
称谓：首次"职务+全名"（美国总统特朗普），后文用姓（特朗普）；机构首次全称
时间：一律"9 月 16 日"格式；跨年时补年份
```

**c. 自检清单（输出前逐条打勾）**：
```
1. 每句是否只含一个事实？
2. 是否出现没有输入支撑的数字/实体？
3. 是否有评论性词（凸显/标志着/值得关注）？
4. 导语是否含 Who+What+When？
5. 正文是否 ≥2 句且 ≤4 句？
```

**d. 长度目标与门禁对齐**：60-120 字（目标）/ 50-260（硬门禁），3 句为默认。

### 3.3 HEADLINE_TRANSLATION 改造

```diff
+ 6. 人名/机构使用通用中文译名（特朗普、美联储、欧盟委员会）
+ 7. 保持原文语气强度：may/considering 不得译为"将/决定"
+ 8. 中文标题不超过 26 字，超出时压缩修饰语而不是删事实
+ 9. 数字格式统一：英文 1.2 billion → 12 亿
```

### 3.4 DAILY_OVERVIEW 改造

```diff
+ - 先写当天最重要的一件事（含主体+动作），再串主线，最后观察点
+ - 不得与正文句子重复；同一事实只能用更高抽象层概括
```

### 3.5 FALLBACK_BODY 改造

```diff
+ - 结构同正文：第 1 句导语（Who+What+When），第 2 句细节，第 3 句可选影响
+ - 称谓与数字规范同正文 prompt
```

## 四、工程层优化（与 prompt 同等重要）

| # | 措施 | 说明 | 优先级 |
|---|---|---|---|
| 1 | JSON Schema 强约束 | 用 `response_format={"type":"json_schema"}` 或 instructor/outlines，替代"严格 JSON"口头约定 + 正则清洗 | P1 |
| 2 | Few-shot 示例库 | 每 prompt 2 例（正/负），虚构实体，版本化管理 | P0 |
| 3 | 自检二次调用（可选） | 只对正文做"事实一致性核对"（用备用模型，温度 0，逐句比对 evidence），标出不通过项人工复核 | P2 |
| 4 | 术语表注入 | 维护 `config/glossary.yaml`（人名/机构译名），注入翻译与写作 prompt | P1 |
| 5 | Prompt 版本化 + 回归集 | promptfoo 或 pytest 子集：20-30 条真实用例（例行公告/重大诉讼/多来源冲突） | P1 |
| 6 | 温度参数 | 评分 0；写作 0.2-0.4；翻译 0（当前评分 0.3，写作未显式设置） | P0 |
| 7 | max_tokens | 当前未设置，长输出可能被默认值截断；写作设 2000、评分设 4000 | P0 |
| 8 | 超长输入治理 | 评分 content 截断 220 字偏短，易误判；建议按 tier 分级（tier1 600 字 / 其他 300 字） | P1 |

## 附：改造前后对照示例

**改造前（现线上）**：
> 9 月 16 日，多家媒体报道，美国众议院通过伊朗战争权力决议，限制特朗普对伊动武权限；半岛电视台报道称，7 名共和党人投下赞成票，《卫报》标题提到这是众议院第三次投票结束伊朗战争，并提及已披露 380 亿美元成本。同日，共和党议员马西在众议院提出针对防长赫格塞思的弹劾条款……接下来，总统对伊动武权限、赫格塞思职位和两党国会议员的投票站位将受这一程序影响。

问题：一句堆 4+ 事实、含分析推断（"将受这一程序影响"无材料支撑）、句式模板。

**改造后（目标）**：
> 9 月 16 日，美国众议院第三次通过限制总统对伊朗动武的战争权力决议，7 名共和党人投赞成票。同日，共和党议员马西提出针对防长赫格塞思的弹劾条款。众议院此前披露的伊朗行动成本为 380 亿美元。

三句：导语（What+Who+When）→ 第二事实 → 可核实数字；无议论、无模板句、每句一事。
