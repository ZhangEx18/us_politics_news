# 2026-07-08 每日算法专题

> 如何在线性时间内，为数组中的每个元素找到它右侧第一个更大的元素？

## 直觉理解

暴力做法是对每个位置都向右扫一遍，直到找到第一个比它大的数；这样虽然直观，但重复比较太多。单调栈的核心想法，是把“还没等到答案的元素”按某种顺序暂时存起来，并且让栈里保持单调性。对于“下一个更大元素”问题，我们通常维护一个从栈底到栈顶递减的栈。这样，新来的元素一旦比栈顶大，就说明它正好是栈顶那个元素右侧第一个更大的数，可以立刻把栈顶弹出并记录答案。因为每个元素最多入栈一次、出栈一次，所以所有比较都被摊平了，复杂度从双重循环降到线性。你可以把这个过程理解成“右边出现了一个更强的候选者，就把之前更弱、且被它压过的元素一次性结算掉”。

## 算法思路

先明确目标：对数组中的每个位置 i，找到它右边第一个严格大于 nums[i] 的元素；如果不存在，就记为 -1。最直接的暴力解法是对每个 i 从 i+1 往右扫描，但在最坏情况下会退化成 O(n^2)。单调栈的关键是避免重复扫描。

做法是从左到右遍历数组，并维护一个栈，栈中存的是“还没有找到下一个更大元素”的下标，同时保证这些下标对应的数值从栈底到栈顶单调递减。当前元素 nums[i] 到来时，只要它比栈顶对应的值更大，就说明 nums[i] 是栈顶元素右边遇到的第一个更大元素；于是不断弹出栈顶，并把这些位置的答案都设为 nums[i]。这一步看起来像是在“批量结算”以前积压的问题。等到栈顶不再小于当前值，或者栈为空，再把 i 入栈，继续处理后面的元素。

为什么栈里必须保持递减？因为这样才能确保：一旦某个新元素比栈顶大，它也一定比栈顶下面那些更小的元素大，但它们是否也能被这次结算，要看它们是否还在等待更近的、更小范围内的答案。按这个规则，弹出的顺序天然就是“谁先失去资格，谁先结算”。最后栈里剩下的元素，右侧已经没有更大元素了，答案保持为 -1 即可。这个思路可以直接扩展到“下一个更小元素”“前一个更大元素”等一类问题，核心都是用单调性减少无效比较。

## Python 示例

```python
from typing import List


def next_greater_elements(nums: List[int]) -> List[int]:
    """
    返回每个元素右侧第一个更大的元素；如果不存在，返回 -1。
    栈中保存下标，保证对应值从栈底到栈顶单调递减。
    """
    n = len(nums)
    ans = [-1] * n
    stack = []  # 存放还没找到答案的下标

    for i, x in enumerate(nums):
        # 当前元素比栈顶更大，说明它就是栈顶元素的“下一个更大元素”
        while stack and nums[stack[-1]] < x:
            idx = stack.pop()
            ans[idx] = x
        stack.append(i)

    return ans


def brute_force_next_greater(nums: List[int]) -> List[int]:
    """
    暴力校验用：对每个位置向右扫描。
    """
    n = len(nums)
    ans = [-1] * n
    for i in range(n):
        for j in range(i + 1, n):
            if nums[j] > nums[i]:
                ans[i] = nums[j]
                break
    return ans


if __name__ == "__main__":
    tests = [
        [2, 1, 2, 4, 3],
        [1, 2, 3, 4],
        [4, 3, 2, 1],
        [1, 1, 1],
        [2, 7, 3, 5, 4, 6, 8],
        [],
        [5],
    ]

    for nums in tests:
        fast = next_greater_elements(nums)
        slow = brute_force_next_greater(nums)
        print(f"nums = {nums}")
        print(f"单调栈结果 = {fast}")
        print(f"暴力校验   = {slow}")
        print(f"是否一致   = {fast == slow}")
        print("-" * 40)

```

## C++ 对照

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> nextGreaterElements(const vector<int>& nums) {
    int n = (int)nums.size();
    vector<int> ans(n, -1);
    stack<int> st; // 存下标，栈中对应值保持单调递减

    for (int i = 0; i < n; ++i) {
        while (!st.empty() && nums[st.top()] < nums[i]) {
            int idx = st.top();
            st.pop();
            ans[idx] = nums[i];
        }
        st.push(i);
    }

    return ans;
}

int main() {
    vector<vector<int>> tests = {
        {2, 1, 2, 4, 3},
        {1, 2, 3, 4},
        {4, 3, 2, 1},
        {1, 1, 1},
        {2, 7, 3, 5, 4, 6, 8},
        {},
        {5}
    };

    for (const auto& nums : tests) {
        auto ans = nextGreaterElements(nums);
        cout << "nums = [";
        for (size_t i = 0; i < nums.size(); ++i) {
            if (i) cout << ", ";
            cout << nums[i];
        }
        cout << "]\n";

        cout << "答案 = [";
        for (size_t i = 0; i < ans.size(); ++i) {
            if (i) cout << ", ";
            cout << ans[i];
        }
        cout << "]\n";
        cout << string(40, '-') << "\n";
    }

    return 0;
}

```

## 复杂度分析

每个元素最多入栈一次、出栈一次，因此总时间复杂度是 O(n)。栈里最多保存 n 个下标，额外空间复杂度是 O(n)。相比暴力枚举的 O(n^2)，单调栈把大量重复比较压缩掉了。

## 易错点

1. 把栈里存成数值而不是下标：如果数组中有重复元素，后续写答案时容易分不清对应位置。修复方法是优先存下标，再通过下标访问原数组。
2. 把比较条件写反或写成 <=：本题要求的是“严格更大”，如果用 <=，会把相等元素错误地当成答案；修复方法是只在 nums[stack[-1]] < 当前值 时弹栈。
3. 遍历结束后忘记处理剩余元素：栈里残留的位置右侧没有更大元素，答案应保持 -1；修复方法是初始化答案数组为 -1，不需要额外清理也能正确得到结果。
