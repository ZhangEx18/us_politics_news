单调栈：一次扫描找下一个更大元素

进阶
栈单调栈数组
如何在数组中快速找到每个元素右侧第一个比它更大的元素？

直觉理解

如果直接暴力做法，就是对每个位置向右一个个扫，直到找到更大的数为止。这样最坏会重复比较很多次，比如数组越接近单调递减，重复劳动就越严重。单调栈的核心想法是：把“暂时还没找到答案”的元素按某种顺序保存起来，并且让它们始终保持一种单调性。这样一来，新来的元素只需要和栈顶比较，就能连续解决一批元素的答案，而不会反复回头检查。你可以把栈想成一个“待处理名单”，名单里的人都在等右边第一个更大的人出现；一旦来了一个更大的数，就把它左边所有比它小、还没被解决的人一次性出栈并填答案。每个元素最多进栈一次、出栈一次，所以整体就从双循环的线性多倍复杂度，优化成了真正的线性复杂度。

算法思路

这类问题的目标是：对数组中的每个元素，找到它右侧第一个严格更大的元素。如果用暴力方法，外层枚举位置 i，内层从 i+1 开始向右找第一个满足条件的值，时间复杂度是 O(n^2)。单调栈的优化思路是“边扫描边结算”。 具体做法是维护一个栈，栈中存放的是元素下标，且这些下标对应的值保持严格递减。为什么要递减？因为栈顶元素是当前最“容易被解决”的那个：如果新元素 nums[i] 比栈顶值更大，那么它一定也能成为栈顶下面那些比它更小元素的下一个更大元素，于是我们不断弹栈，直到栈顶不再小于 nums[i]。每弹出一个下标 j，就说明 nums[i] 是 nums[j] 右边第一个更大的元素，可以直接记录答案为 nums[i]。 当处理完所有比当前元素小的栈顶后，再把当前下标 i 入栈，等待未来更大的元素来解决它。由于每个元素只会入栈一次、出栈一次，所以总操作量是 O(n)。 如果题目问的是“下一个更大元素的值”，答案数组里存值即可；如果问的是“下一个更大元素的下标”，就存下标；如果要处理循环数组，只需把数组遍历两遍，但第二遍只负责“唤醒”之前未解决的元素，不再重复入栈即可。这个框架非常通用，适合一切“找右边第一个满足某种单调条件的位置”的问题。

Python 示例

from typing import List


def next_greater_elements(nums: List[int]) -> List[int]:
    """返回每个元素右侧第一个更大元素；若不存在则为 -1。"""
    n = len(nums)
    ans = [-1] * n
    stack = []  # 存下标，且对应值保持单调递减

    for i, x in enumerate(nums):
        # 当前元素比栈顶元素大，说明它可以作为栈顶元素的下一个更大元素
        while stack and nums[stack[-1]] < x:
            j = stack.pop()
            ans[j] = x
        stack.append(i)

    return ans


if __name__ == "__main__":
    tests = [
        [2, 1, 2, 4, 3],
        [1, 3, 4, 2],
        [5, 4, 3, 2, 1],
        [1, 2, 3, 4, 5],
        [2, 2, 2],
    ]

    for arr in tests:
        print("原数组:", arr)
        print("答案  :", next_greater_elements(arr))
        print("-")

C++ 对照

#include <bits/stdc++.h>
using namespace std;

vector<int> nextGreaterElements(const vector<int>& nums) {
    int n = (int)nums.size();
    vector<int> ans(n, -1);
    stack<int> st; // 存下标，且对应值保持单调递减

    for (int i = 0; i < n; ++i) {
        while (!st.empty() && nums[st.top()] < nums[i]) {
            int j = st.top();
            st.pop();
            ans[j] = nums[i];
        }
        st.push(i);
    }
    return ans;
}

int main() {
    vector<vector<int>> tests = {
        {2, 1, 2, 4, 3},
        {1, 3, 4, 2},
        {5, 4, 3, 2, 1},
        {1, 2, 3, 4, 5},
        {2, 2, 2}
    };

    for (auto& arr : tests) {
        cout << "原数组: ";
        for (int x : arr) cout << x << ' ';
        cout << "\n答案  : ";
        auto ans = nextGreaterElements(arr);
        for (int x : ans) cout << x << ' ';
        cout << "\n-\n";
    }
    return 0;
}

复杂度分析

每个元素最多入栈一次、出栈一次，因此总时间复杂度是 O(n)。栈中最多保存 n 个下标，额外空间复杂度是 O(n)。这种优化的关键不在于单次操作更快，而在于避免了重复扫描右侧区间。

易错点

  1. 把栈里存成值而不是下标，后续无法准确回填答案或区分重复元素。修复方法：优先存下标，比较时再通过 nums[下标] 取值。
  2. 把比较条件写成 <= 或 >=，导致等于时被错误弹出或错误保留。修复方法：如果题意是“严格更大”，弹栈条件必须是 nums[st[-1]] < 当前值。
  3. 误以为每次入栈前都要先把栈清空。修复方法：只弹出比当前元素小的连续栈顶，保留比当前元素大的旧元素继续等待更大的答案。

延伸练习

  1. 基础题：把本题改成“下一个更小元素”，要求输出每个位置右侧第一个更小的值。
