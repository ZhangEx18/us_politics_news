单调栈：线性找到下一个更大元素

进阶
栈单调栈数组
如何把“对每个元素都向右暴力找更大值”的双循环，优化成一次遍历的线性算法？

直觉理解

如果每个位置都自己往右看，最坏情况下会反复比较很多次，比如数组递减时，前面的元素几乎要把后面的所有元素都扫一遍。单调栈的核心想法是：把“还没找到答案的元素”按顺序放进栈里，并且让栈顶到栈底保持单调。当前元素一来，只要它比栈顶更大，就说明它正好是栈顶那个元素的“下一个更大元素”，于是立刻结算并弹出。这样每个元素最多进栈一次、出栈一次，很多原本重复的比较被提前消掉了。栈里保留的，不是已经完成任务的元素，而是仍在等待更大值出现的元素。换句话说，单调栈是在用“后来的大元素”批量回答“之前的小元素”的问题。这个技巧特别适合处理数组中“左边/右边第一个满足条件的位置”这一类问题。

算法思路

先明确目标：对数组中的每个元素，找到它右侧第一个比它大的元素；如果不存在，就记为 -1。最直接的方法是对每个位置向右扫描，但这样会产生双重循环，时间复杂度是 O(n^2)。 单调栈的做法是从左到右遍历数组，栈里保存“还没有找到下一个更大元素”的下标。为了让结算高效，栈中元素对应的值保持一个单调递减结构，也就是从栈底到栈顶，值越来越小。为什么要递减？因为当前元素一旦足够大，就可以连续解决一串更小的元素。 具体操作如下：遍历到当前位置 i，当前值为 x。只要栈不空，并且 x 大于栈顶下标对应的值，就说明 x 是栈顶元素右侧遇到的第一个更大元素。此时把栈顶弹出，并把答案记为 x。这个过程可以循环进行，因为当前元素可能一次性解决多个等待中的元素。等所有比 x 小的元素都处理完后，再把 i 压入栈中，继续向后扫描。 遍历结束后，栈中剩下的元素说明右侧已经没有更大的数了，它们的答案统一保持为 -1 即可。这个思路的关键不是“栈能存数据”，而是“栈维护了未完成元素的相对顺序和单调性”，让每个元素只经历有限次进出栈操作，从而把重复比较压缩掉。实际编码时，通常用下标入栈，这样既能比较数值，也能回填答案位置，写法更稳。

Python 示例

from typing import List


def next_greater_elements(nums: List[int]) -> List[int]:
    """返回每个元素右侧第一个更大元素，若不存在则为 -1。"""
    n = len(nums)
    ans = [-1] * n
    stack: List[int] = []  # 存下标，栈中对应的值保持单调递减

    for i, x in enumerate(nums):
        # 当前元素 x 可以解决所有比它小的栈顶元素
        while stack and nums[stack[-1]] < x:
            idx = stack.pop()
            ans[idx] = x
        stack.append(i)

    return ans


if __name__ == '__main__':
    # 基础测试
    nums1 = [2, 1, 2, 4, 3]
    print(next_greater_elements(nums1))
    assert next_greater_elements(nums1) == [4, 2, 4, -1, -1]

    # 全递减：每个元素都找不到更大值
    nums2 = [5, 4, 3, 2, 1]
    print(next_greater_elements(nums2))
    assert next_greater_elements(nums2) == [-1, -1, -1, -1, -1]

    # 含重复元素：相等不算更大
    nums3 = [1, 1, 1, 2]
    print(next_greater_elements(nums3))
    assert next_greater_elements(nums3) == [2, 2, 2, -1]

    # 单元素
    nums4 = [42]
    print(next_greater_elements(nums4))
    assert next_greater_elements(nums4) == [-1]

    print('全部测试通过')

C++ 对照

#include <iostream>
#include <vector>
#include <stack>
using namespace std;

vector<int> nextGreaterElements(const vector<int>& nums) {
    int n = (int)nums.size();
    vector<int> ans(n, -1);
    stack<int> st; // 存下标，栈中对应的值保持单调递减

    for (int i = 0; i < n; ++i) {
        while (!st.empty() && nums[st.top()] < nums[i]) {
            ans[st.top()] = nums[i];
            st.pop();
        }
        st.push(i);
    }
    return ans;
}

int main() {
    vector<int> nums1 = {2, 1, 2, 4, 3};
    vector<int> ans1 = nextGreaterElements(nums1);
    for (int x : ans1) cout << x << ' ';
    cout << '\n';

    vector<int> nums2 = {5, 4, 3, 2, 1};
    vector<int> ans2 = nextGreaterElements(nums2);
    for (int x : ans2) cout << x << ' ';
    cout << '\n';

    return 0;
}

复杂度分析

每个元素最多入栈一次、出栈一次，遍历过程中所有 while 弹栈的总次数是 O(n)，所以总时间复杂度为 O(n)。栈里最坏情况下会存下整个数组的下标，因此空间复杂度是 O(n)。这就是单调栈相对暴力枚举的核心优势：把重复比较压缩成了可控的线性操作。

易错点

  1. 把“更大”写成了“更大或等于”。例如 1,1,2 中，前两个 1 的下一个更大元素是 2，不是后面的 1；比较条件应使用 `nums[stack[-1]] < x`，不要写成 `<=`。
  2. 栈里存值而不是存下标，导致无法正确回填答案位置。修复方法是入栈时保存下标，比较时通过下标访问原数组，答案也直接写到对应位置。
  3. 把栈维护成单调递增，导致当前元素无法一次性解决一批更小元素。正确方向应是从栈底到栈顶单调递减，这样当前较大的数才能连续弹出多个等待项。

延伸练习

  1. 改写成“下一个更小元素”，要求返回每个元素右侧第一个更小的数。
  2. 在本题基础上处理环形数组：数组末尾后面接回开头，求每个元素的下一个更大元素。
