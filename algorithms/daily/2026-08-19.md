# 2026-08-19 每日算法专题

> 如何用一次线性遍历，快速找到每个元素右侧第一个更大的数？

## 直觉理解

暴力做法里，每个元素都向右一路找，最坏会变成双重循环。单调栈的思路是：把“还没找到答案的元素”按某种顺序压在栈里，让栈顶始终代表最容易被当前元素解决的那个。以“下一个更大元素”为例，栈里保存的是一个从栈底到栈顶单调递减的序列。这样一来，新来的元素只要比栈顶大，就说明它正好是栈顶元素右边遇到的第一个更大值，可以立刻把栈顶弹出并记录答案；如果还比新的栈顶大，就继续处理。每个元素最多进栈一次、出栈一次，所以虽然看起来有 while 循环，整体仍然是线性的。它的本质不是“神奇地跳过了比较”，而是把重复比较集中到一次维护单调性的过程里，把未来可能多次发生的工作提前整理好。

## 算法思路

先明确问题：对数组中的每个位置 i，找到它右侧第一个严格大于 nums[i] 的元素；如果不存在，答案记为 -1。最直接的方法是对每个 i 向右扫描，但这样会重复比较很多次。单调栈的核心是维护“尚未找到下一个更大元素”的下标，并让对应值保持单调递减。这样当一个新元素 nums[i] 到来时，它会不断“解决”栈顶那些比它小的元素，因为对这些元素来说，nums[i] 就是它们右侧遇到的第一个更大值。具体做法是：从左到右遍历数组，栈中存下标而不是数值，这样既能比较大小，也能方便回写答案。对于当前元素 nums[i]，只要栈不空且 nums[i] > nums[栈顶]，就把栈顶下标弹出，并令答案[栈顶] = nums[i]。循环结束后，把当前下标 i 入栈，表示它自己还在等待右侧更大的元素。遍历结束后，栈中剩下的元素都没有找到更大值，答案保持 -1 即可。这个框架非常通用：如果题目改成“下一个更小元素”，只需要把比较方向反过来；如果要求循环数组中的下一个更大元素，则再把数组长度扩展一倍来模拟环形结构。写代码时最容易出错的地方有两个：一是误把“下一个更大”写成“更大或相等”，二是只存值不存下标，导致无法准确回填答案。

## Python 示例

```python
from typing import List


def next_greater_elements(nums: List[int]) -> List[int]:
    """
    返回每个元素右侧第一个更大的元素。
    如果不存在，返回 -1。
    """
    n = len(nums)
    ans = [-1] * n
    stack = []  # 存放下标，栈内对应的 nums 值保持单调递减

    for i, x in enumerate(nums):
        # 当前元素比栈顶元素大，说明它就是栈顶元素右侧第一个更大元素
        while stack and x > nums[stack[-1]]:
            idx = stack.pop()
            ans[idx] = x
        # 当前元素还没有找到答案，先入栈等待后面的元素来解决
        stack.append(i)

    return ans


def brute_force_next_greater(nums: List[int]) -> List[int]:
    """
    暴力对照实现，用于验证单调栈结果。
    """
    n = len(nums)
    ans = [-1] * n
    for i in range(n):
        for j in range(i + 1, n):
            if nums[j] > nums[i]:
                ans[i] = nums[j]
                break
    return ans


if __name__ == "__main__":
    tests = [
        [2, 1, 2, 4, 3],
        [1, 3, 2, 4],
        [5, 4, 3, 2, 1],
        [2, 2, 2],
        [1],
        [],
    ]

    for nums in tests:
        fast = next_greater_elements(nums)
        slow = brute_force_next_greater(nums)
        print(f"nums = {nums}")
        print(f"单调栈结果 = {fast}")
        print(f"暴力对照 = {slow}")
        assert fast == slow
        print("通过\n")

```

## C++ 对照

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> nextGreaterElements(const vector<int>& nums) {
    int n = (int)nums.size();
    vector<int> ans(n, -1);
    stack<int> st; // 存下标，栈内对应值保持单调递减

    for (int i = 0; i < n; ++i) {
        while (!st.empty() && nums[i] > nums[st.top()]) {
            ans[st.top()] = nums[i];
            st.pop();
        }
        st.push(i);
    }

    return ans;
}

int main() {
    vector<vector<int>> tests = {
        {2, 1, 2, 4, 3},
        {1, 3, 2, 4},
        {5, 4, 3, 2, 1},
        {2, 2, 2},
        {1},
        {}
    };

    for (const auto& nums : tests) {
        auto ans = nextGreaterElements(nums);
        cout << "nums = [";
        for (size_t i = 0; i < nums.size(); ++i) {
            if (i) cout << ", ";
            cout << nums[i];
        }
        cout << "]\nans  = [";
        for (size_t i = 0; i < ans.size(); ++i) {
            if (i) cout << ", ";
            cout << ans[i];
        }
        cout << "]\n\n";
    }

    return 0;
}

```

## 复杂度分析

每个元素最多入栈一次、出栈一次，所以总时间复杂度是 O(n)。栈中在最坏情况下会保存全部元素，因此空间复杂度是 O(n)。虽然代码里有 while 循环，但它不是嵌套放大复杂度，而是把每个元素的弹出过程摊还到整体遍历中。

## 易错点

1. 把比较条件写成 `>=` 或 `<=`，会把相等元素误当成更大元素；正确要求通常是“严格更大”，需要根据题意精确区分。
2. 只存数值不存下标，后面虽然知道弹出的值是什么，却无法把答案写回原位置；实际实现里应优先存下标。
3. 遍历方向和入栈时机弄反，例如先把当前元素入栈再去处理它，会把自己和自己比较，破坏“右侧第一个更大元素”的语义。
