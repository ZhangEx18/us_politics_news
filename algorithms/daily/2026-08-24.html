单调栈：线性求解下一个更大元素

进阶
栈单调栈数组
如何在一次遍历中，快速找到数组中每个元素右侧第一个比它大的元素？

直觉理解

想象一排正在等待答案的人：每个人都想知道右边第一个比自己高的人是谁。暴力方法会让每个人依次向右寻找，许多比较会被重复执行。单调栈把那些暂时没有找到答案、并且从栈底到栈顶保持递减的人保存起来。当新元素到来时，只要它比栈顶元素大，就说明它正好可以成为栈顶元素的“下一个更大元素”，弹出并记录答案；如果它还不够大，就继续等待。被弹出的元素永远不必再次处理，而新元素也会进入栈中等待未来的更大值。这样，每个元素最多入栈一次、出栈一次，重复搜索被压缩成了线性过程。

算法思路

先创建一个与原数组等长的答案数组，默认值设为 -1，表示右侧不存在更大元素。再准备一个栈，但栈中保存的是尚未找到答案的元素下标，而不是元素值；使用下标既能访问数值，也能在需要时计算距离。按照从左到右的顺序扫描数组。处理当前下标 i 时，反复比较当前值 nums[i] 与栈顶下标对应的值：只要 nums[i] 更大，栈顶元素的答案就确定为 nums[i]，弹出该下标并写入答案。停止弹栈后，把 i 压入栈，等待后面的元素处理。由于栈内从栈底到栈顶对应的数值始终保持严格递减，所以当前元素只需处理那些可能被它解决的候选者。扫描结束时，栈中剩余下标右侧都没有更大元素，答案保持 -1。若题目要求“下一个更大或相等元素”，弹栈条件应改为 nums[i] >= nums[stack[-1]]；严格大于和大于等于必须根据题意选择。

Python 示例

def next_greater_elements(nums):
    """返回每个元素右侧第一个更大的元素，不存在时返回 -1。"""
    # ans[i] 保存 nums[i] 的答案，-1 表示暂时或最终没有更大元素
    ans = [-1] * len(nums)

    # 栈中保存下标，对应元素值从栈底到栈顶严格递减
    stack = []

    for i, value in enumerate(nums):
        # 当前元素可以解决栈顶元素的等待状态。
        # 只要当前值更大，就持续弹出已经找到答案的下标。
        while stack and value > nums[stack[-1]]:
            waiting_index = stack.pop()
            ans[waiting_index] = value

        # 当前元素右侧的答案尚未确定，压入栈中等待后续元素。
        stack.append(i)

    # 扫描结束后，栈中剩余元素右侧不存在更大值，答案仍为 -1。
    return ans


if __name__ == "__main__":
    test_cases = [
        ([2, 1, 2, 4, 3], [4, 2, 4, -1, -1]),
        ([1, 3, 2, 4], [3, 4, 4, -1]),
        ([5, 4, 3, 2, 1], [-1, -1, -1, -1, -1]),
        ([], []),
    ]

    for nums, expected in test_cases:
        actual = next_greater_elements(nums)
        print(f"输入：{nums}")
        print(f"输出：{actual}")
        assert actual == expected

    print("所有测试通过")

C++ 对照

#include <cassert>
#include <iostream>
#include <stack>
#include <vector>

using namespace std;

vector<int> nextGreaterElements(const vector<int>& nums) {
    vector<int> ans(nums.size(), -1);
    stack<int> st;

    for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
        while (!st.empty() && nums[i] > nums[st.top()]) {
            ans[st.top()] = nums[i];
            st.pop();
        }
        st.push(i);
    }

    return ans;
}

int main() {
    vector<int> nums = {2, 1, 2, 4, 3};
    vector<int> expected = {4, 2, 4, -1, -1};
    vector<int> actual = nextGreaterElements(nums);

    assert(actual == expected);
    for (int value : actual) {
        cout << value << ' ';
    }
    cout << "\n测试通过\n";
    return 0;
}

复杂度分析

时间复杂度为 O(n)。虽然单次处理当前元素时可能连续弹出多个下标，但每个下标最多入栈一次、出栈一次，因此所有 while 循环累计执行次数不超过 n。空间复杂度为 O(n)：答案数组需要 O(n) 空间，单调栈在最坏情况下也可能保存全部元素。若题目允许原数组直接作为答案存储，仍需根据实现方式判断是否能真正减少额外栈空间。

易错点

  1. 把元素值而不是下标压入栈，后续遇到重复值时无法准确区分位置；应始终保存下标，通过 nums[index] 获取对应值。
  2. 将弹栈条件误写成 >=，会把相等元素当成更大元素，违反“严格更大”的题意；严格下一个更大元素使用 value > nums[stack[-1]]，题目明确允许相等时才使用 >=。
  3. 扫描结束后忘记处理栈中剩余元素，导致它们的答案未定义；初始化答案为 -1，并确认剩余下标确实应保持 -1。

延伸练习

  1. 给定数组 [4, 5, 2, 10, 8]，使用单调栈求每个元素右侧第一个更大元素，并手动写出每一步栈内下标的变化。
  2. 将算法改造成“循环数组中的下一个更大元素”：数组末尾之后重新从数组开头继续查找，要求时间复杂度仍为 O(n)，例如输入 [1, 2, 1]，输出 [2, -1, 2]。
