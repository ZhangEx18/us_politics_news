单调栈：线性解决下一个更大元素

进阶
栈单调栈数组
如何用栈维护单调性，把“找右边第一个更大元素”的暴力枚举优化到线性时间？

直觉理解

把数组想成一排人，每个人都在等待右边第一个比自己高的人出现。暴力做法是：对每个人向右逐个看，直到找到更高的人为止，这样最坏会反复扫很多次。单调栈的核心想法，是把“还没等到答案的人”按某种顺序放进栈里，始终让栈顶最容易被解决。对于“下一个更大元素”，我们从左到右扫描，每来一个新数，就把它和栈顶的人比较：如果新数更大，说明栈顶等待的答案已经出现了，直接弹出并记录；如果还不够大，就继续等待。这样，每个元素最多进栈一次、出栈一次，所有比较都变成“顺手处理”，不会重复回头看。单调栈的本质不是“记住更多信息”，而是“让未来能一次性解决过去的一串问题”。

算法思路

先明确问题：对数组中的每个元素，找到它右侧第一个严格大于它的元素；如果不存在，结果记为 `-1`。暴力做法是对每个位置从右往后扫描，直到找到答案，复杂度是 `O(n^2)`。单调栈把这个过程改成“边走边结算”。 具体做法是从左到右遍历数组，栈里存放的是“还没找到下一个更大元素的下标”，并且保证这些下标对应的元素值从栈底到栈顶保持单调递减。为什么要递减？因为栈顶元素最小，最容易被当前新元素击败；一旦当前值 `x` 比栈顶元素大，就说明栈顶元素的答案已经找到了，答案就是 `x`。接着继续判断新的栈顶，直到栈顶元素不再小于 `x`，或者栈为空。 每次弹栈时，顺便把被弹出的元素的答案写入结果数组。当前元素处理完后，再把它入栈，等待未来更大的元素来解决它。遍历结束后，栈中剩下的元素都没有找到更大元素，它们的答案保持为 `-1`。 这个框架特别适合处理“右边第一个满足条件的位置”这类问题。关键不是栈本身，而是“当新元素到来时，能否一次性解决一批旧元素”。如果能，就很适合用单调栈。实现时常用“下标入栈”，这样既能比较数值，也能回填答案位置，代码更通用。

Python 示例

from typing import List


def next_greater_elements(nums: List[int]) -> List[int]:
    """返回每个位置右侧第一个更大元素；若不存在则为 -1。"""
    n = len(nums)
    ans = [-1] * n
    stack = []  # 存下标，栈中对应的 nums 值保持单调递减

    for i, x in enumerate(nums):
        # 当前元素比栈顶元素大，说明它可以成为栈顶元素的“下一个更大元素”
        while stack and nums[stack[-1]] < x:
            idx = stack.pop()
            ans[idx] = x
        # 当前元素还没有找到答案，先入栈等待未来更大的元素
        stack.append(i)

    return ans


if __name__ == "__main__":
    # 测试用例 1：基础示例
    nums1 = [2, 1, 2, 4, 3]
    print("输入:", nums1)
    print("输出:", next_greater_elements(nums1))  # 期望 [4, 2, 4, -1, -1]

    # 测试用例 2：严格递减，所有元素都找不到更大元素
    nums2 = [5, 4, 3, 2, 1]
    print("输入:", nums2)
    print("输出:", next_greater_elements(nums2))  # 期望 [-1, -1, -1, -1, -1]

    # 测试用例 3：有重复元素
    nums3 = [1, 3, 3, 2, 4]
    print("输入:", nums3)
    print("输出:", next_greater_elements(nums3))  # 期望 [3, 4, 4, 4, -1]

C++ 对照

#include <bits/stdc++.h>
using namespace std;

vector<int> nextGreaterElements(const vector<int>& nums) {
    int n = (int)nums.size();
    vector<int> ans(n, -1);
    stack<int> st; // 存下标，保证对应值单调递减

    for (int i = 0; i < n; ++i) {
        while (!st.empty() && nums[st.top()] < nums[i]) {
            ans[st.top()] = nums[i];
            st.pop();
        }
        st.push(i);
    }
    return ans;
}

int main() {
    vector<vector<int>> tests = {
        {2, 1, 2, 4, 3},
        {5, 4, 3, 2, 1},
        {1, 3, 3, 2, 4}
    };

    for (const auto& nums : tests) {
        auto ans = nextGreaterElements(nums);
        cout << "输入: ";
        for (int x : nums) cout << x << ' ';
        cout << "\n输出: ";
        for (int x : ans) cout << x << ' ';
        cout << "\n\n";
    }
    return 0;
}

复杂度分析

每个元素最多入栈一次、出栈一次，因此总时间复杂度是 `O(n)`。栈中最坏会保存全部元素，所以空间复杂度是 `O(n)`。相比暴力双循环的 `O(n^2)`，单调栈把重复比较压缩成了线性扫描。

易错点

  1. 把“严格更大”写成了“更大等于”。如果题目要求下一个更大元素，比较条件应使用 `<` 弹栈，不能用 `<=`，否则重复元素会被错误跳过；修复方法是先确认题意，再统一比较符号。
  2. 只存数值不存下标，导致无法回填答案位置。很多题目需要给每个原位置写答案，栈里必须存下标，比较时通过 `nums[stack[-1]]` 取值；修复方法是默认优先存下标，除非题目明确不需要位置。
  3. 扫描方向和答案含义混淆。这个写法是从左到右求“右侧第一个更大元素”，如果改成从右到左，栈的含义会变；修复方法是先确定你要找的是“右边第一个”还是“左边第一个”，再选择遍历方向与单调方向。
