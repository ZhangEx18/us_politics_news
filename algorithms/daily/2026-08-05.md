# 2026-08-05 每日算法专题

> 如何对数组中的每个元素，在不使用暴力双循环的情况下，快速找到它右侧第一个比它大的元素？

## 直觉理解

想象一排人从左到右站着，每个人都想知道右边第一个比自己高的人。暴力方法会让每个人逐个向右寻找，最坏需要比较很多次。单调栈提供了另一种视角：从左到右观察新元素，如果它比栈顶元素大，那么它就可以成为栈顶元素的“下一个更大元素”，持续弹出所有比它矮的人。栈中留下的元素对应的候选答案仍然没有出现，因此按照从栈底到栈顶的顺序，它们的值保持递减。每个元素最多入栈一次、出栈一次，所以虽然代码中有循环嵌套，实际总操作次数仍然是线性的。

## 算法思路

以“下一个更大元素”为例，维护一个存放元素下标的单调递减栈。下标比直接存数值更灵活，因为既能比较数组值，也能在找到答案时回写结果。开始时所有位置的答案都设为 -1，表示右侧不存在更大元素。遍历数组中的每个位置 i：如果栈不为空且当前值 nums[i] 大于栈顶下标对应的值，说明 nums[i] 正是该栈顶元素右侧遇到的第一个更大值，将结果写入 answer[栈顶]，然后弹出栈顶。由于当前元素可能同时解决多个较矮元素的问题，因此要持续弹出，直到栈为空或栈顶值不小于当前值。处理完所有可解决的元素后，把 i 压入栈，等待未来更大的元素来解决它。最后仍留在栈中的位置右侧没有更大元素，答案保持 -1。严格来说，栈保存的是“尚未找到答案的候选位置”，单调性保证每个元素无需被反复比较。

## Python 示例

```python
def next_greater_elements(nums):
    """返回每个元素右侧第一个更大的元素；不存在时返回 -1。"""
    n = len(nums)
    answer = [-1] * n
    # 栈中保存尚未找到答案的元素下标，且对应值从栈底到栈顶递减
    stack = []

    for i, value in enumerate(nums):
        # 当前值可以解决所有比它小的栈顶元素
        while stack and nums[stack[-1]] < value:
            index = stack.pop()
            answer[index] = value

        # 当前元素也要等待右侧未来出现更大的元素
        stack.append(i)

    return answer


# 测试用例
if __name__ == "__main__":
    test_cases = [
        ([2, 1, 2, 4, 3], [4, 2, 4, -1, -1]),
        ([1, 3, 4, 2], [3, 4, -1, -1]),
        ([5, 4, 3, 2, 1], [-1, -1, -1, -1, -1]),
        ([2, 2, 3], [3, 3, -1]),
    ]

    for nums, expected in test_cases:
        actual = next_greater_elements(nums)
        print(f"数组：{nums}")
        print(f"结果：{actual}")
        assert actual == expected

    print("所有测试用例通过！")
```

## C++ 对照

```cpp
#include <cassert>
#include <iostream>
#include <vector>

using namespace std;

vector<int> nextGreaterElements(const vector<int>& nums) {
    int n = static_cast<int>(nums.size());
    vector<int> answer(n, -1);
    // 栈中保存下标，对应值从栈底到栈顶递减
    vector<int> stack;

    for (int i = 0; i < n; ++i) {
        while (!stack.empty() && nums[stack.back()] < nums[i]) {
            int index = stack.back();
            stack.pop_back();
            answer[index] = nums[i];
        }
        stack.push_back(i);
    }

    return answer;
}

int main() {
    vector<int> nums = {2, 1, 2, 4, 3};
    vector<int> expected = {4, 2, 4, -1, -1};
    vector<int> actual = nextGreaterElements(nums);

    assert(actual == expected);
    cout << "所有测试用例通过！\n";
    return 0;
}
```

## 复杂度分析

时间复杂度为 O(n)。虽然每次遍历中包含 while 循环，但每个下标只会入栈一次、最多出栈一次，因此所有出栈操作加起来不超过 n 次。空间复杂度为 O(n)，最坏情况下数组单调递减，所有元素都会暂时保存在栈中；答案数组也需要 O(n) 空间。

## 易错点

1. 把栈写成存放元素值而不是下标，导致找到答案后无法准确回写原位置；应存下标，并通过 nums[stack[-1]] 比较对应值。
2. 遇到一个更大元素时只弹出一次，遗漏它同时解决多个较小元素的情况；应使用 while 循环持续弹出，直到栈为空或栈顶值不小于当前值。
3. 将相等元素错误地当成更大元素处理，或误用 <= 导致重复值被提前弹出；题目要求严格更大时使用 nums[stack[-1]] < value，相等元素保留在栈中。

## 延伸练习

1. 给定数组 [73, 74, 75, 71, 69, 72, 76, 73]，使用单调栈求每个元素右侧第一个更大元素，并改写程序返回“距离”而不是返回更大元素的数值。
2. 解决“循环数组的下一个更大元素”：数组末尾之后可以继续从数组开头寻找，要求时间复杂度为 O(n)，提示是遍历 2n 个位置并使用 i % n 访问原数组。
