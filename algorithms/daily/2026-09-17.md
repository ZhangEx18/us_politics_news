# 2026-09-17 每日算法专题

> 如何在线性时间内求出数组中每个元素右侧第一个比它大的元素？

## 直觉理解

把数组想成一排人，每个人都想知道右边第一个比自己高的人是谁。暴力做法是每个人都向右张望，最坏要看 O(n^2) 次。单调栈像一个只保留“还没等到答案”的人的等待区：等待区里从栈底到栈顶身高递减，栈顶最矮。新来一个人时，只要他比栈顶的人高，栈顶的人就等到了右边第一个更高者，立刻记录答案并离开等待区；继续比较，直到新人不再比栈顶高，再让新人入栈等待。为什么不会错过？因为被弹出的人已经拿到了当前新人这个答案，而没被弹出的人仍然从栈底到栈顶递减，未来更高的人出现时也不会跳过顺序。每个人最多进等待区一次、离开一次，所以等待和结算都不重复，整体从暴力双循环变成线性扫描。

## 算法思路

从左到右扫描数组，维护一个存储下标的栈。栈内元素对应的 nums 值从栈底到栈顶严格递减，表示这些位置还没有找到下一个更大元素。
步骤：
1. 初始化答案数组 ans 全部为 -1，因为找不到更大元素时答案就是 -1。
2. 遍历 i 从 0 到 n-1，记当前值为 x=nums[i]。
3. 当栈非空且 nums[栈顶] < x 时：设栈顶下标为 idx，那么 x 就是 idx 右侧第一个比 nums[idx] 大的值，令 ans[idx]=x，并弹出 idx。重复直到栈顶值不小于 x。
4. 把 i 压入栈，等待未来更大的元素来结算它。
5. 遍历结束后，栈中剩下的下标右侧没有更大元素，ans 保持 -1。
正确性关键在“第一个”：如果 idx 和 i 之间存在一个比 nums[idx] 大的值，它在扫描到时会先弹出 idx，因此当前 x 才是第一个。条件必须用严格小于，等于不算更大；否则 [1,1,2] 中第一个 1 会被错误地认为下一个更大是第二个 1。整体每个下标入栈一次、出栈至多一次，扫描是线性的。

## Python 示例

```python
def next_greater_element(nums):
    n = len(nums)
    ans = [-1] * n
    stack = []  # 存下标，栈内 nums[stack] 从栈底到栈顶严格递减

    for i, x in enumerate(nums):
        # 当前 x 比栈顶元素大，x 就是栈顶元素的下一个更大元素
        while stack and nums[stack[-1]] < x:
            idx = stack.pop()
            ans[idx] = x
        stack.append(i)

    return ans


def brute_force(nums):
    # 暴力法，仅用于验证
    n = len(nums)
    ans = [-1] * n
    for i in range(n):
        for j in range(i + 1, n):
            if nums[j] > nums[i]:
                ans[i] = nums[j]
                break
    return ans


if __name__ == '__main__':
    test_cases = [
        ([2, 1, 2, 4, 3], [4, 2, 4, -1, -1]),
        ([1, 3, 2, 4], [3, 4, 4, -1]),
        ([5, 4, 3, 2, 1], [-1, -1, -1, -1, -1]),
        ([1, 1, 2], [2, 2, -1]),
        ([], []),
    ]

    for nums, expected in test_cases:
        got = next_greater_element(nums)
        print(nums, '->', got)
        assert got == expected, f'期望 {expected}，得到 {got}'

    import random
    for _ in range(2000):
        n = random.randint(0, 15)
        nums = [random.randint(-10, 10) for _ in range(n)]
        assert next_greater_element(nums) == brute_force(nums), nums

    print('全部测试通过')

```

## C++ 对照

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> nextGreaterElement(const vector<int>& nums) {
    int n = nums.size();
    vector<int> ans(n, -1);
    vector<int> st; // 存下标，栈内对应值从栈底到栈顶严格递减

    for (int i = 0; i < n; ++i) {
        while (!st.empty() && nums[st.back()] < nums[i]) {
            ans[st.back()] = nums[i];
            st.pop_back();
        }
        st.push_back(i);
    }
    return ans;
}

int main() {
    vector<int> nums = {2, 1, 2, 4, 3};
    vector<int> ans = nextGreaterElement(nums);
    for (int x : ans) {
        cout << x << ' ';
    }
    cout << '\n';
    return 0;
}

```

## 复杂度分析

时间复杂度 O(n)。外层循环遍历 n 个元素，每个元素最多入栈一次，因此也最多出栈一次；while 循环所有轮次合计最多弹出 n 次，均摊到每次遍历是 O(1)。空间复杂度 O(n)。答案数组占 O(n)，单调栈最坏情况下也占 O(n)，例如数组严格递减时所有元素都留在栈中。相比暴力枚举每个位置右侧所有元素的最坏 O(n^2)，单调栈把重复比较合并成了每个元素一次入栈、一次出栈。

## 易错点

1. 把 while 条件写成 nums[stack[-1]] <= x。这样等于当前值的元素也会被弹出，但“下一个更大”要求严格大于。修复：使用 nums[stack[-1]] < x，等于时保留在栈里。
2. 栈里只存元素值，最后无法把答案写回原数组对应下标。修复：栈中存下标 i，通过 nums[stack[-1]] 取值比较，通过 stack.pop() 回填 ans。
3. 先入栈再结算，或结算后忘记入栈。正确顺序是：先 while 弹出所有能被当前 x 结算的下标，再 stack.append(i)；否则当前元素可能被自己或错误顺序处理。
4. 遍历结束后没有处理栈中剩余下标。如果 ans 已初始化为 -1 就无需再写；若初始化为 0 或空，会留下错误答案。

## 延伸练习

1. 基础：给定整数数组，求每个位置右侧第一个更小元素，找不到返回 -1。把单调栈的递减关系反过来即可。
2. 拓展：循环数组中的下一个更大元素（LeetCode 503）。将数组长度扩展到 2n 或取模扫描，只回填原始下标，注意每个元素最多入栈一次。
3. 进阶：每日温度（LeetCode 739），返回每个温度之后第一个更高温度出现的天数；本质是下标差值形式的下一个更大元素。
