# 2026-07-21 每日算法专题

> 如何把每个元素右侧第一个比它大的数，从双重遍历优化成一次线性扫描？

## 直觉理解

如果你想知道数组里每个数右边第一个比它大的数，最直接的想法是：对每个位置都往右看，直到找到更大的元素为止。这种做法简单，但很多比较其实是在重复劳动。单调栈的核心，就是把“已经看过、但还没等到答案”的元素按一定顺序暂时存起来，让后来的元素来统一结算。对于“下一个更大元素”问题，我们维护一个从栈底到栈顶递减的栈：栈里放的是还没找到更大值的下标。当一个新元素出现时，只要它比栈顶元素大，就说明它正好是栈顶那个元素右边遇到的第一个更大元素，于是立刻把栈顶弹出并记录答案。这个过程像一群人排队等更高的人出现，谁先被“超过”，谁就先得到结果。每个元素最多进栈一次、出栈一次，所以整体就从可能的平方级，变成了干净利落的线性时间。

## 算法思路

先明确问题：对数组中的每个位置 i，寻找它右侧第一个比 nums[i] 大的元素；如果不存在，就记为 -1。暴力解法会对每个 i 向右扫描，最坏要做 O(n^2) 次比较。单调栈的思路是，把“还没找到答案”的元素按值维护成单调递减结构，这样后面一旦出现更大的数，就能一次性解决一批旧元素。

具体做法是从左到右遍历数组。栈中存下标而不是直接存值，因为我们不仅要比较大小，还要方便把答案写回对应位置。对于当前元素 nums[i]，只要栈不为空且 nums[i] 大于栈顶下标对应的值，就说明 nums[i] 是这个栈顶元素右边第一个更大的数。于是不断弹栈，并把答案数组中对应位置填成 nums[i]。当当前元素无法再“打败”栈顶时，说明它暂时还不能帮助更早的元素，便把自己的下标压入栈中，等待未来更大的数来结算。

这个方法成立的关键在于“第一个更大”四个字：因为我们是按从左到右扫描，当前元素第一次让某个旧元素出栈时，已经保证它左边没有更早的更大元素，否则那个旧元素早就被处理了。遍历结束后，栈里剩下的元素说明它们右侧再也没有更大的数，答案保持 -1 即可。这个模板不仅能解决下一个更大元素，也能迁移到下一个更小元素、每日温度、接雨水等经典题目，核心都是用单调性减少重复比较。

## Python 示例

```python
from typing import List


def next_greater_elements(nums: List[int]) -> List[int]:
    """
    返回每个元素右侧第一个更大的元素；如果不存在则返回 -1。
    这里使用单调递减栈，栈中存的是下标。
    """
    n = len(nums)
    ans = [-1] * n
    stack: List[int] = []  # 维护单调递减栈：对应值从栈底到栈顶递减

    for i, x in enumerate(nums):
        # 当前元素 x 让栈顶元素“等到了答案”
        while stack and nums[stack[-1]] < x:
            j = stack.pop()
            ans[j] = x
        # 当前下标入栈，等待未来更大的元素
        stack.append(i)

    return ans


if __name__ == "__main__":
    tests = [
        ([2, 1, 2, 4, 3], [4, 2, 4, -1, -1]),
        ([1, 2, 3, 4], [2, 3, 4, -1]),
        ([4, 3, 2, 1], [-1, -1, -1, -1]),
        ([2, 2, 2], [-1, -1, -1]),
        ([1, 3, 2, 5, 4], [3, 5, 5, -1, -1]),
    ]

    for nums, expected in tests:
        result = next_greater_elements(nums)
        print(f"nums={nums}, result={result}, expected={expected}")
        assert result == expected

    print("所有测试通过")

```

## C++ 对照

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> nextGreaterElements(const vector<int>& nums) {
    int n = (int)nums.size();
    vector<int> ans(n, -1);
    stack<int> st; // 存下标，保持对应值单调递减

    for (int i = 0; i < n; ++i) {
        while (!st.empty() && nums[st.top()] < nums[i]) {
            int j = st.top();
            st.pop();
            ans[j] = nums[i];
        }
        st.push(i);
    }

    return ans;
}

int main() {
    vector<pair<vector<int>, vector<int>>> tests = {
        {{2, 1, 2, 4, 3}, {4, 2, 4, -1, -1}},
        {{1, 2, 3, 4}, {2, 3, 4, -1}},
        {{4, 3, 2, 1}, {-1, -1, -1, -1}},
        {{2, 2, 2}, {-1, -1, -1}},
        {{1, 3, 2, 5, 4}, {3, 5, 5, -1, -1}}
    };

    for (const auto& [nums, expected] : tests) {
        auto result = nextGreaterElements(nums);
        cout << "nums = [";
        for (size_t i = 0; i < nums.size(); ++i) {
            cout << nums[i] << (i + 1 == nums.size() ? "" : ", " );
        }
        cout << "], result = [";
        for (size_t i = 0; i < result.size(); ++i) {
            cout << result[i] << (i + 1 == result.size() ? "" : ", " );
        }
        cout << "], expected = [";
        for (size_t i = 0; i < expected.size(); ++i) {
            cout << expected[i] << (i + 1 == expected.size() ? "" : ", " );
        }
        cout << "]\n";
        assert(result == expected);
    }

    cout << "所有测试通过\n";
    return 0;
}

```

## 复杂度分析

每个元素最多入栈一次、出栈一次，因此总时间复杂度是 O(n)。栈和答案数组都需要额外空间，空间复杂度是 O(n)。相比暴力做法的 O(n^2)，单调栈把重复比较压缩成了线性扫描。

## 易错点

1. 把栈里存值而不是存下标，导致无法正确回填答案；修复方法是统一存下标，用下标去访问原数组和值数组。
2. 弹栈条件写成 `<=` 却没有想清楚重复元素的语义，可能把相等元素误判为更大；修复方法是明确题目要求是“严格更大”，因此只在 `nums[stack[-1]] < x` 时弹栈。
3. 忘记初始化答案为 -1，或在遍历结束后遗漏栈中剩余元素；修复方法是先把答案数组全部设为 -1，剩余元素无需额外处理。
