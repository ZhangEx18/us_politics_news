单调栈：线性找出下一个更大元素

进阶
栈单调栈数组
如何在一次遍历中，为每个元素快速找到右侧第一个比它大的元素？

直觉理解

如果直接对每个位置向右扫描，最坏情况下会变成双重循环，时间复杂度是 O(n^2)。单调栈的想法，是把“还没找到答案的元素”按某种顺序暂时存起来，并且让这个顺序始终保持有用。对于下一个更大元素问题，我们从左到右扫描数组，栈里保存那些右边还没遇到更大元素的数值或下标，而且它们对应的值保持单调递减。这样一来，新来的元素只要比栈顶大，就说明它可以作为栈顶元素的“下一个更大元素”，于是立刻弹出并记录答案。一个元素一旦被弹出，就说明它的答案已经确定，不需要再回头看。每个元素最多入栈一次、出栈一次，所以整体就从暴力枚举优化成了线性时间。单调栈的本质不是“神奇地快”，而是把重复比较提前整理掉，让未来的决策只依赖当前栈顶。

算法思路

这类题的核心框架是“扫描 + 维护候选答案”。先明确题目要的是右侧第一个更大的元素，因此我们按从左到右的顺序遍历数组。遍历时维护一个单调递减栈，栈中放的是还没有找到下一个更大元素的位置。当前元素记为 x：如果 x 比栈顶元素大，说明栈顶元素的答案找到了，x 就是它右侧第一个更大元素；不断弹栈，直到栈空或者栈顶不小于 x。随后把当前元素压入栈，等待未来更大的数来解决它。这样做的关键，是栈中元素的值从栈底到栈顶保持递减，保证每次只需要检查栈顶，就能把一批已经“被当前元素解决”的位置一次性处理完。若题目要求输出每个位置的下一个更大元素值，可以开一个结果数组，初始化为 -1，弹栈时直接写入答案；若题目要求的是下标，也可以把下标压栈，比较时通过下标访问原数组。最后，栈里剩下的元素说明右侧没有更大元素，答案保持默认值即可。这个模式不仅能用于“下一个更大元素”，也能推广到“下一个更小元素”“温度计问题”“每日温度”等一类题目。

Python 示例

from typing import List


def next_greater_elements(nums: List[int]) -> List[int]:
    """
    返回每个位置右侧第一个比它大的元素；如果不存在，返回 -1。
    使用单调递减栈，栈中存放下标。
    """
    n = len(nums)
    ans = [-1] * n
    stack: List[int] = []  # 栈中保存下标，保证对应值单调递减

    for i, x in enumerate(nums):
        # 当前元素比栈顶对应的值大，说明栈顶元素找到了答案
        while stack and nums[stack[-1]] < x:
            idx = stack.pop()
            ans[idx] = x
        # 当前元素还没有找到更大的元素，先入栈等待后续处理
        stack.append(i)

    return ans


def run_tests() -> None:
    cases = [
        ([2, 1, 2, 4, 3], [4, 2, 4, -1, -1]),
        ([1, 2, 3, 4], [2, 3, 4, -1]),
        ([4, 3, 2, 1], [-1, -1, -1, -1]),
        ([2, 2, 2], [-1, -1, -1]),
        ([1, 5, 3, 6, 4], [5, 6, 6, -1, -1]),
    ]

    for nums, expected in cases:
        result = next_greater_elements(nums)
        assert result == expected, f"输入 {nums} 期望 {expected}，得到 {result}"

    print("所有测试通过")


if __name__ == "__main__":
    run_tests()

C++ 对照

#include <iostream>
#include <vector>
#include <stack>
using namespace std;

vector<int> nextGreaterElements(const vector<int>& nums) {
    int n = (int)nums.size();
    vector<int> ans(n, -1);
    stack<int> st; // 栈中存下标，保证对应值单调递减

    for (int i = 0; i < n; ++i) {
        while (!st.empty() && nums[st.top()] < nums[i]) {
            int idx = st.top();
            st.pop();
            ans[idx] = nums[i];
        }
        st.push(i);
    }
    return ans;
}

void printVector(const vector<int>& v) {
    for (size_t i = 0; i < v.size(); ++i) {
        if (i) cout << ' ';
        cout << v[i];
    }
    cout << '\n';
}

int main() {
    vector<vector<int>> tests = {
        {2, 1, 2, 4, 3},
        {1, 2, 3, 4},
        {4, 3, 2, 1},
        {2, 2, 2},
        {1, 5, 3, 6, 4}
    };

    for (const auto& nums : tests) {
        vector<int> ans = nextGreaterElements(nums);
        printVector(ans);
    }

    return 0;
}

复杂度分析

每个元素最多入栈一次、出栈一次，因此时间复杂度是 O(n)。栈中最多保存 n 个下标，结果数组也需要 O(n) 空间，所以总空间复杂度是 O(n)。单调栈把原本可能重复比较很多次的工作压缩成了摊还常数次操作。

易错点

  1. 把栈里存的值和下标混淆，导致无法正确回填答案。修复方法是统一存下标，比较时通过下标访问原数组。
  2. 把比较条件写成 `<=` 或 `<` 时没有先想清楚题意。若题目要求“严格更大”，应该用 `<` 弹栈；如果写成 `<=`，相等元素会被错误地当成更大元素处理。
  3. 遍历结束后忘记处理栈中剩余元素。其实这些元素右侧没有更大值，应该保持默认值 `-1`，不要再额外修改。

延伸练习

  1. 改写代码，输出每个元素右侧第一个更小元素，要求只改动比较逻辑。
