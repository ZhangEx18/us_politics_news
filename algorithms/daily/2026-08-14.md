# 2026-08-14 每日算法专题

> 如何把“对每个元素向右找第一个更大值”的双重循环，优化成一次遍历就能完成的线性算法？

## 直觉理解

如果对数组里每个数都向右挨个比较，最坏情况下会做很多重复工作。单调栈的核心想法是：把“暂时还没等到答案”的元素按一定顺序存起来，让后来的元素一来，就能顺手解决一批旧问题。对于下一个更大元素，我们维护一个从栈底到栈顶严格递减的栈。这样栈顶元素最“弱”，一旦遇到更大的新元素，它就立刻找到答案；如果新元素还不够大，就继续往后等。每个元素最多入栈一次、出栈一次，所以虽然看起来像在不断弹栈，整体仍然是线性的。这个结构本质上是在用“保留有价值的候选者”代替“反复扫描所有人”，把暴力比较变成了有纪律的等待。

## 算法思路

题目通常要求：给定一个数组，求每个位置右侧第一个比它大的数；如果不存在，就记为 -1。直接做法是对每个位置向右扫描，直到找到更大的元素为止，代码简单，但复杂度是 O(n^2)。单调栈把这个过程改造成“边走边结算”。

具体做法是从左到右遍历数组，栈中存放的是“还没找到下一个更大元素”的下标或数值，并且保持对应值从栈底到栈顶单调递减。当前遍历到元素 x 时，只要栈顶元素比 x 小，说明 x 就是它右边遇到的第一个更大元素，可以立刻把答案更新为 x，并把这个栈顶弹出。这个过程会连续发生，直到栈顶不小于 x 或栈为空。然后把当前元素压入栈，等待未来更大的元素来处理它。

这样设计的关键在于：栈里保留的都是“还没有被更大的右侧元素击败”的候选项，且它们按大小排好序。每个元素只会经历一次入栈和一次出栈，所以总成本是线性的。实现时常用“下标栈”而不是“值栈”，这样既能比较数值，又能在答案数组中回填对应位置。若题目是环形数组、两个数组映射或需要找左侧信息，也可以在这个框架上稍作改造，但核心仍是同一件事：利用单调性消灭重复比较。

下面给出一个标准版本：返回每个元素右侧第一个更大元素的值。遍历时维护一个递减栈，遇到更大值就不断结算栈顶。最后栈中剩余元素说明右侧不存在更大值，答案保持 -1 即可。

## Python 示例

```python
from typing import List


def next_greater_elements(nums: List[int]) -> List[int]:
    """
    返回每个元素右侧第一个更大元素。
    如果不存在，则返回 -1。
    """
    n = len(nums)
    ans = [-1] * n
    stack = []  # 存放下标，栈中对应的 nums 值保持严格递减

    for i, x in enumerate(nums):
        # 只要当前元素更大，就可以结算栈顶元素的答案
        while stack and nums[stack[-1]] < x:
            idx = stack.pop()
            ans[idx] = x
        stack.append(i)

    return ans


def _run_tests():
    cases = [
        ([2, 1, 2, 4, 3], [4, 2, 4, -1, -1]),
        ([1, 2, 3, 4], [2, 3, 4, -1]),
        ([4, 3, 2, 1], [-1, -1, -1, -1]),
        ([2, 2, 2], [-1, -1, -1]),
        ([1, 5, 3, 6, 4, 8], [5, 6, 6, 8, 8, -1]),
    ]

    for nums, expected in cases:
        result = next_greater_elements(nums)
        assert result == expected, f"nums={nums}, expected={expected}, got={result}"

    print("全部测试通过")


if __name__ == "__main__":
    _run_tests()
```

## C++ 对照

```cpp
#include <iostream>
#include <vector>
#include <stack>
using namespace std;

vector<int> nextGreaterElements(const vector<int>& nums) {
    int n = (int)nums.size();
    vector<int> ans(n, -1);
    stack<int> st; // 存下标，保持对应值单调递减

    for (int i = 0; i < n; ++i) {
        while (!st.empty() && nums[st.top()] < nums[i]) {
            ans[st.top()] = nums[i];
            st.pop();
        }
        st.push(i);
    }

    return ans;
}

int main() {
    vector<vector<int>> tests = {
        {2, 1, 2, 4, 3},
        {1, 2, 3, 4},
        {4, 3, 2, 1},
        {2, 2, 2},
        {1, 5, 3, 6, 4, 8}
    };

    for (const auto& nums : tests) {
        vector<int> ans = nextGreaterElements(nums);
        for (int x : ans) cout << x << ' ';
        cout << '\n';
    }

    return 0;
}
```

## 复杂度分析

每个元素最多进栈一次、出栈一次，因此总时间复杂度是 O(n)。栈中最多保存 n 个下标，答案数组也需要 O(n) 空间，所以空间复杂度是 O(n)。相比暴力枚举的 O(n^2)，单调栈把重复比较压缩掉了。

## 易错点

1. 把栈里存成数值却没有保留下标，导致无法正确回填对应位置的答案；修复方法是优先存下标，比较时再取 nums[下标]。
2. 把弹栈条件写成 `<=`，会把相等元素也当成更大元素处理，结果错误；修复方法是严格使用 `<`，因为题目要的是“更大”而不是“更大或相等”。
3. 只在遍历结束后统一处理栈，没有在遍历过程中更新答案，导致错过“当前元素就是前面某些元素的第一个更大值”；修复方法是每次读到新元素，都先把它能结算的栈顶全部结算掉。
