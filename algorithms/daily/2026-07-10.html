单调栈与下一个更大元素

进阶
栈单调栈数组
如何把“找每个元素右边第一个更大值”的暴力双循环，优化到线性时间？

直觉理解

下一个更大元素这类题的关键，不是“每个位置都重新扫一遍右边”，而是把已经看过的、还没找到答案的元素统一管理起来。单调栈做的事很像“待处理名单”：栈里放着那些暂时还没遇到更大值的下标，并且保持从栈底到栈顶对应的值单调递减。这样一来，当新元素 `x` 出现时，只要它比栈顶元素大，就说明栈顶元素的“下一个更大元素”就是 `x`，可以立刻结案并弹出；如果还比新的栈顶也大，就继续结案，直到栈顶不再小于 `x`。每个元素最多进栈一次、出栈一次，所以虽然表面上像在反复比较，整体却是线性的。它本质上是在用“维护局部有序关系”替代“重复扫描”。

算法思路

这类题最常见的目标是：对数组中的每个元素，找到它右边第一个比它大的元素；如果不存在，就记为 `-1`。直接做法是对每个位置向右扫描，最坏会到 `O(n^2)`。单调栈把这个过程改写成“边遍历边解决未完成问题”。 具体做法是从左到右遍历数组，栈中保存的是下标，而不是值。这样做有两个好处：第一，可以通过下标回写答案；第二，遇到重复值时也能准确区分位置。栈要保持“对应值严格递减”。当我们读到当前元素 `nums[i]` 时，只要栈顶下标 `j` 满足 `nums[i] > nums[j]`，就说明 `nums[j]` 右边第一个更大的元素已经找到了，就是当前值 `nums[i]`。于是把 `ans[j]` 设为 `nums[i]`，然后弹出 `j`。这个过程会持续进行，直到栈空或者栈顶元素不再小于当前值。 为什么这样正确：因为栈中元素按从左到右的出现顺序压入，且值递减。对于栈顶元素来说，当前这个新元素是它右侧第一个比它大的元素；如果中间还存在更大的元素，那个元素在遍历时就已经把它弹出了，不会留到现在。处理完当前元素后，把它自己的下标压栈，等待未来更大的元素来“结案”。遍历结束后，栈里剩下的元素右侧已经没有更大的值，答案保持为 `-1`。 这套框架可以直接套到很多变体上：找右边第一个更大、右边第一个更小、温度升高、柱状图边界等。唯一变化的是单调方向和比较符号。写代码时，重点是先想清楚“栈里存的是什么”以及“栈要保持什么单调性”，再去写 `while` 弹栈逻辑。

Python 示例

from typing import List


def next_greater_elements(nums: List[int]) -> List[int]:
    """返回每个元素右侧第一个更大元素；不存在则为 -1。"""
    n = len(nums)
    ans = [-1] * n
    stack = []  # 存下标，栈中对应的 nums 值保持单调递减

    for i, x in enumerate(nums):
        # 当前元素比栈顶元素大，说明找到了栈顶元素的下一个更大元素
        while stack and nums[stack[-1]] < x:
            idx = stack.pop()
            ans[idx] = x
        stack.append(i)

    return ans


def _run_tests() -> None:
    tests = [
        ([2, 1, 2, 4, 3], [4, 2, 4, -1, -1]),
        ([1, 2, 3, 4], [2, 3, 4, -1]),
        ([4, 3, 2, 1], [-1, -1, -1, -1]),
        ([2, 2, 2], [-1, -1, -1]),
        ([1, 3, 2, 4], [3, 4, 4, -1]),
        ([], []),
    ]

    for nums, expected in tests:
        got = next_greater_elements(nums)
        assert got == expected, f"输入 {nums}, 期望 {expected}, 得到 {got}"

    print("所有测试通过")


if __name__ == "__main__":
    _run_tests()

C++ 对照

#include <bits/stdc++.h>
using namespace std;

vector<int> nextGreaterElements(const vector<int>& nums) {
    int n = (int)nums.size();
    vector<int> ans(n, -1);
    stack<int> st; // 存下标，保持对应值单调递减

    for (int i = 0; i < n; ++i) {
        while (!st.empty() && nums[st.top()] < nums[i]) {
            int idx = st.top();
            st.pop();
            ans[idx] = nums[i];
        }
        st.push(i);
    }

    return ans;
}

int main() {
    vector<vector<int>> tests = {
        {2, 1, 2, 4, 3},
        {1, 2, 3, 4},
        {4, 3, 2, 1},
        {2, 2, 2},
        {1, 3, 2, 4},
        {}
    };

    vector<vector<int>> expected = {
        {4, 2, 4, -1, -1},
        {2, 3, 4, -1},
        {-1, -1, -1, -1},
        {-1, -1, -1},
        {3, 4, 4, -1},
        {}
    };

    for (size_t t = 0; t < tests.size(); ++t) {
        auto got = nextGreaterElements(tests[t]);
        assert(got == expected[t]);
    }

    cout << "所有测试通过" << endl;
    return 0;
}

复杂度分析

每个元素最多入栈一次、出栈一次，因此总时间复杂度是 `O(n)`。栈在最坏情况下会保存全部元素，例如数组严格递减时，所以空间复杂度是 `O(n)`。相比双重循环的 `O(n^2)`，单调栈的提升来自于把重复比较集中到“弹栈结算”这一动作里。

易错点

  1. 把栈里存成“值”而不是“下标”，导致重复元素时无法准确回写答案。修复方法：统一存下标，用 `nums[index]` 访问值。
  2. 弹栈条件写错成 `<=` 或反过来。若题目要求“严格更大”，就应使用 `<` 触发弹栈；若写成 `<=`，相等元素会被误判成更大，结果出错。先明确题意，再定比较符号。
  3. 没有在遍历结束后保留未匹配元素的默认值。修复方法：先把答案数组初始化为 `-1`，这样栈里剩余元素自然表示右侧不存在更大值。

延伸练习

  1. 基础练习：把题目改成“下一个更小元素”，要求返回每个元素右侧第一个更小的值，并说明栈的单调方向如何改变。
  2. 拓展练习：完成“每日温度”问题，返回每一天还要等待多少天才能迎来更高温度，要求在单调栈基础上把答案从“值”改成“距离”。
