单调栈：线性求下一个更大元素

进阶
栈单调栈数组
如何在数组中为每个元素快速找到右侧第一个比它大的元素？

直觉理解

暴力做法是对每个位置都向右扫一遍，直到找到第一个更大的数；如果数组很长，这会重复比较很多次。单调栈的核心想法，是把“暂时还没找到答案”的元素按一定顺序放在栈里，并且保证这个顺序一直有效。对于“下一个更大元素”这类问题，栈里通常维护一个从栈底到栈顶递减的序列。这样一来，当新元素到来时，只要它比栈顶大，就说明它就是栈顶元素右侧第一个更大的数，因为栈顶之前挡着它的那些更小元素都已经被它顺手解决了。每个元素最多进栈一次、出栈一次，所以整体就从双循环的平方复杂度降到了线性复杂度。这个技巧本质上是在用“维护候选答案”的方式，避免重复扫描。

算法思路

先明确目标：对数组中每个位置 i，寻找它右边第一个比 nums[i] 更大的元素。如果不存在，就记为 -1。最直接的方法是双重循环，但它会反复做无效比较，最坏是 O(n^2)。 单调栈的做法是从左到右遍历数组，栈中保存“还没有找到下一个更大元素”的下标，并且让这些下标对应的值保持单调递减。为什么要递减？因为这样新来的元素 x 才能一次性解决一串更小的元素。具体做法是：当遍历到 nums[i] 时，只要栈不空并且 nums[i] > nums[栈顶]，就说明 nums[i] 是栈顶位置的下一个更大元素，直接把答案写成 nums[i]，然后把栈顶弹出。重复这个过程，直到栈空或栈顶元素不小于 nums[i]。最后把当前下标 i 入栈，等待未来更大的数来处理。 这个过程非常高效，因为每个元素只会入栈一次、出栈一次。栈里保留的是“还没被解决的元素”，而且它们从底到顶越来越小，保证了新元素一来就能批量结算。若题目要求的是“右侧第一个更大元素”，从左到右扫描最自然；若要求的是“左侧第一个更大元素”，则扫描方向和维护方式会相应调整。实现时通常保存下标而不是数值，这样既能回填答案数组，也能处理重复元素。 如果题目是环形数组，可以把数组看成长度翻倍，做两轮遍历，但栈中只保留原始下标，并且只在第一次遍历时真正入栈。这样仍然能保持线性复杂度。对于基础版“下一个更大元素”，掌握“栈内单调递减、遇到更大值就结算”的模式，就已经覆盖了大量同类题目。

Python 示例

from typing import List


def next_greater_elements(nums: List[int]) -> List[int]:
    """返回每个元素右侧第一个更大元素；若不存在则为 -1。"""
    n = len(nums)
    ans = [-1] * n
    stack = []  # 存下标，栈中对应值保持单调递减

    for i, x in enumerate(nums):
        # 当前元素 x 可以作为栈顶元素的下一个更大元素
        while stack and x > nums[stack[-1]]:
            j = stack.pop()
            ans[j] = x
        stack.append(i)

    return ans


if __name__ == "__main__":
    # 测试用例 1：标准示例
    nums1 = [2, 1, 2, 4, 3]
    print(next_greater_elements(nums1))  # 预期: [4, 2, 4, -1, -1]

    # 测试用例 2：严格递增
    nums2 = [1, 2, 3, 4]
    print(next_greater_elements(nums2))  # 预期: [2, 3, 4, -1]

    # 测试用例 3：严格递减
    nums3 = [5, 4, 3, 2, 1]
    print(next_greater_elements(nums3))  # 预期: [-1, -1, -1, -1, -1]

    # 测试用例 4：存在重复元素
    nums4 = [2, 2, 1, 2, 3]
    print(next_greater_elements(nums4))  # 预期: [3, 3, 2, 3, -1]

C++ 对照

#include <bits/stdc++.h>
using namespace std;

vector<int> nextGreaterElements(const vector<int>& nums) {
    int n = (int)nums.size();
    vector<int> ans(n, -1);
    stack<int> st; // 存下标，保证对应值单调递减

    for (int i = 0; i < n; ++i) {
        while (!st.empty() && nums[i] > nums[st.top()]) {
            int j = st.top();
            st.pop();
            ans[j] = nums[i];
        }
        st.push(i);
    }

    return ans;
}

int main() {
    vector<vector<int>> tests = {
        {2, 1, 2, 4, 3},
        {1, 2, 3, 4},
        {5, 4, 3, 2, 1},
        {2, 2, 1, 2, 3}
    };

    for (const auto& nums : tests) {
        vector<int> ans = nextGreaterElements(nums);
        for (int x : ans) cout << x << ' ';
        cout << '\n';
    }

    return 0;
}

复杂度分析

每个元素最多入栈一次、出栈一次，因此总时间复杂度为 O(n)。答案数组和栈都只需要线性额外空间，空间复杂度为 O(n)。相比双重循环的 O(n^2)，单调栈的优势在于把重复比较压缩掉了。

易错点

  1. 把栈里存成数值而不是下标，导致重复元素时无法正确回填答案；修复方法是存下标，答案直接写回对应位置。
  2. 栈的单调方向写反了：本题应维护递减栈，才能让当前更大的数一次性结算一串更小元素；如果维护成递增栈，逻辑会失效。
  3. 只在遇到更大元素时弹一次，忘了用 while 连续弹栈；修复方法是持续弹出所有比当前元素小的下标，直到栈空或栈顶不再更小。

延伸练习

  1. 实现一个函数，返回每个元素左侧第一个更大元素，要求仍然是 O(n) 复杂度。
  2. 把本题扩展到环形数组：对于每个位置，寻找循环意义下右侧第一个更大元素。
