# 2026-08-08 每日算法专题

> 如何用动态规划高效计算爬到第 n 阶楼梯的不同走法数？

## 直觉理解

爬楼梯是动态规划最经典的入门题：每次可以走 1 阶或 2 阶，问爬到第 n 阶共有多少种方法。直觉上，你站在第 n 阶时，最后一步只有两种可能：要么从第 n-1 阶走 1 步上来，要么从第 n-2 阶走 2 步上来。于是，爬到第 n 阶的方法数，就等于爬到第 n-1 阶的方法数加上爬到第 n-2 阶的方法数。这个关系非常像“拆成最后一步”的思考方式，把一个大问题拆成两个更小、结构相同的问题。继续往前看，你会发现第 3 阶、第 4 阶、第 5 阶……都能用同样方式推出来，这就是递推。动态规划做的事情，就是把这些子问题的答案按顺序保存下来，避免重复计算。最初可以用一个数组记录每一阶的答案，最后再发现其实只需要保留前两个状态，就能把空间压缩到常数级。这个题虽然简单，但它完整展示了状态定义、状态转移和空间优化三个核心概念。

## 算法思路

解这道题时，先把问题翻成“到达某一阶有多少种方案”。设 dp[i] 表示爬到第 i 阶的方法数，那么目标就是求 dp[n]。接着思考状态转移：如果最后一步走了 1 阶，那么前一刻一定在第 i-1 阶；如果最后一步走了 2 阶，那么前一刻一定在第 i-2 阶。两类情况互不重叠，所以 dp[i] = dp[i-1] + dp[i-2]。这一步是整个题的核心。然后补上边界：dp[0] 可以理解为“站在地面上”的 1 种方法，dp[1] = 1；如果按照题意也可以直接设 dp[1] = 1、dp[2] = 2，再从 3 开始递推。实现时，先用数组版最容易理解：从前往后计算每个 dp[i]，直到 dp[n]。这能帮助建立动态规划的直觉。之后再观察状态转移只依赖前两个值，所以不必保存整个数组，只用两个变量分别表示前一项和前两项，就能一边迭代一边更新，空间从 O(n) 优化到 O(1)。这类优化在很多线性递推题里都很常见，掌握它会让你对动态规划从“会写”进阶到“会省”。

## Python 示例

```python
from typing import List


def climb_stairs(n: int) -> int:
    """计算爬到第 n 阶楼梯的方法数。

    每次可以走 1 阶或 2 阶。
    使用滚动数组优化空间，时间 O(n)，空间 O(1)。
    """
    # 边界情况：
    # n = 0 时，表示不动，也算 1 种方式
    if n == 0:
        return 1
    # n = 1 时，只有 1 种走法：1
    if n == 1:
        return 1

    # prev2 表示 dp[i-2]，prev1 表示 dp[i-1]
    prev2 = 1  # dp[0]
    prev1 = 1  # dp[1]

    # 从第 2 阶开始递推
    for _ in range(2, n + 1):
        current = prev1 + prev2  # dp[i] = dp[i-1] + dp[i-2]
        prev2 = prev1
        prev1 = current

    return prev1


if __name__ == "__main__":
    # 测试用例
    test_cases = [
        (0, 1),
        (1, 1),
        (2, 2),
        (3, 3),
        (4, 5),
        (5, 8),
        (10, 89),
    ]

    for n, expected in test_cases:
        result = climb_stairs(n)
        print(f"n={n}, 结果={result}, 期望={expected}, {'通过' if result == expected else '失败'}")

```

## C++ 对照

```cpp
#include <iostream>
#include <vector>
using namespace std;

int climbStairs(int n) {
    // 边界情况
    if (n == 0) return 1;
    if (n == 1) return 1;

    // prev2 表示 dp[i-2]，prev1 表示 dp[i-1]
    int prev2 = 1; // dp[0]
    int prev1 = 1; // dp[1]

    for (int i = 2; i <= n; ++i) {
        int current = prev1 + prev2; // dp[i] = dp[i-1] + dp[i-2]
        prev2 = prev1;
        prev1 = current;
    }

    return prev1;
}

int main() {
    vector<pair<int, int>> testCases = {
        {0, 1}, {1, 1}, {2, 2}, {3, 3}, {4, 5}, {5, 8}, {10, 89}
    };

    for (const auto& [n, expected] : testCases) {
        int result = climbStairs(n);
        cout << "n=" << n << ", 结果=" << result << ", 期望=" << expected
             << ", " << (result == expected ? "通过" : "失败") << endl;
    }

    return 0;
}

```

## 复杂度分析

设 n 为楼梯阶数。状态转移只需要从前两个状态推出当前状态，因此每一阶只计算一次，总时间复杂度为 O(n)。如果使用数组保存全部状态，空间复杂度是 O(n)；如果采用滚动优化，只保留前两个值，空间复杂度可降为 O(1)。

## 易错点

1. 把 dp[0] 和 dp[1] 的含义弄混：有些人直接写 dp[1]=1、dp[2]=2，却在循环起点上出错。修复方法是先统一定义，再从相同的边界推下去，或者明确采用滚动变量时的初始值。
2. 把最后一步的两种情况算重复：有人会把“先走 1 再走 2”和“先走 2 再走 1”误当成同一种，或者在递推里重复加法。修复方法是严格按“最后一步来自哪里”分类，保证每种方案只被统计一次。
3. 忘记处理 n=0 或小输入：直接从第 2 阶开始循环会导致边界值返回错误。修复方法是在编码前先写清楚 base case，再进入递推。
