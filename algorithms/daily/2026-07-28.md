# 2026-07-28 每日算法专题

> 如何在数组中用线性时间为每个元素快速找到右侧第一个更大的数？

## 直觉理解

暴力做法是对每个位置都向右扫一遍，直到遇到更大的元素为止。这样虽然直接，但很多位置会被反复比较，时间很容易退化成平方级。单调栈的核心想法是：把“还没找到答案”的元素按某种顺序暂存起来，并且让这个顺序一直保持单调。这样一来，新来的元素只需要和栈顶比较，就能连续解决一批元素的答案，而不必重复回头检查。对于“下一个更大元素”这类问题，栈里通常维护的是一个从栈底到栈顶单调递减的序列，因为越靠后的元素越可能更早遇到右侧更大的数。当一个新元素比栈顶大时，栈顶就找到了它的下一个更大元素，可以立刻出栈并记录答案；如果新元素还不够大，就先把自己压进去等待后续机会。每个元素最多进栈一次、出栈一次，所以整体效率可以从暴力的双循环压到线性复杂度。

## 算法思路

这类题的标准框架是“从左到右扫描数组，维护一个单调递减栈”。栈中存放的是元素下标，这样既能比较数值，也方便把答案写回原数组的位置。处理到当前位置 `i` 时，当前元素 `nums[i]` 会不断和栈顶元素对应的值比较：只要 `nums[i]` 比栈顶元素大，就说明栈顶那个元素的“下一个更大元素”已经出现了，立刻弹出栈顶，并把答案设为 `nums[i]`。这个过程可能连续发生多次，因为一个新元素可能一次性解决多个更小的元素。弹出结束后，如果栈里还有元素，说明它们都比当前值大，当前元素还不能成为它们的答案，于是把 `i` 入栈，继续等待未来更大的数。遍历结束后，栈中剩下的元素右侧再也没有更大的数，答案统一记为 `-1`。

这个方法的关键是“单调性带来的批量结算”。栈里保存的元素从底到顶对应的数值始终递减，因此当前元素一旦足够大，就会把一串更小的元素全部结算掉。每个元素只会经历一次入栈和一次出栈，因此总操作次数是线性的。实际写题时，建议先想清楚你要的是“右侧第一个更大元素”，还是“左侧第一个更小元素”等变体；只要把单调方向和比较条件改对，模板就能复用。对于重复元素，通常要严格区分“更大”和“更大等于”，比较符号直接决定结果是否会被提前弹出。下面的示例代码会返回每个位置右侧第一个更大元素，不存在则为 `-1`，并附带一个简单测试用例。

## Python 示例

```python
from typing import List


def next_greater_elements(nums: List[int]) -> List[int]:
    """返回每个位置右侧第一个更大元素；若不存在，则为 -1。"""
    n = len(nums)
    ans = [-1] * n
    stack: List[int] = []  # 维护下标，栈中对应的数值保持单调递减

    for i, x in enumerate(nums):
        # 当前元素 x 足够大，就不断结算栈顶元素的答案
        while stack and nums[stack[-1]] < x:
            idx = stack.pop()
            ans[idx] = x
        # 当前元素还没有找到更大元素，先入栈等待
        stack.append(i)

    return ans


if __name__ == "__main__":
    # 测试用例 1
    nums1 = [2, 1, 2, 4, 3]
    print(next_greater_elements(nums1))  # 期望输出: [4, 2, 4, -1, -1]

    # 测试用例 2
    nums2 = [1, 3, 2, 4]
    print(next_greater_elements(nums2))  # 期望输出: [3, 4, 4, -1]

    # 测试用例 3
    nums3 = [5, 5, 5]
    print(next_greater_elements(nums3))  # 期望输出: [-1, -1, -1]

```

## C++ 对照

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> nextGreaterElements(const vector<int>& nums) {
    int n = (int)nums.size();
    vector<int> ans(n, -1);
    stack<int> st; // 维护下标，栈中对应的数值保持单调递减

    for (int i = 0; i < n; ++i) {
        while (!st.empty() && nums[st.top()] < nums[i]) {
            int idx = st.top();
            st.pop();
            ans[idx] = nums[i];
        }
        st.push(i);
    }

    return ans;
}

int main() {
    vector<int> nums1 = {2, 1, 2, 4, 3};
    vector<int> res1 = nextGreaterElements(nums1);
    for (int x : res1) cout << x << ' ';
    cout << '\n';

    vector<int> nums2 = {1, 3, 2, 4};
    vector<int> res2 = nextGreaterElements(nums2);
    for (int x : res2) cout << x << ' ';
    cout << '\n';

    vector<int> nums3 = {5, 5, 5};
    vector<int> res3 = nextGreaterElements(nums3);
    for (int x : res3) cout << x << ' ';
    cout << '\n';

    return 0;
}

```

## 复杂度分析

每个元素最多入栈一次、出栈一次，所以总时间复杂度是 O(n)。栈中最多保存 n 个下标，因此空间复杂度是 O(n)。如果题目只要求返回答案数组，这通常已经是最优的线性解法。

## 易错点

1. 把栈存成值而不是下标，导致无法正确回填答案位置；修复方法是优先存下标，比较时再取 nums[下标]。
2. 把比较条件写成 `<=`，把相等元素也当成更大元素弹出；修复方法是先确认题意是否要求“严格更大”，本题应使用 `<`。
3. 以为出栈后还要继续手动回扫前面的元素，实际上单调栈已经保证这些元素以后不会再被当前值更优地处理；修复方法是只做一次从左到右扫描。
