二叉树 DFS 遍历入门

入门
树DFS递归
如何用递归统一理解二叉树的前序、中序、后序遍历，并形成稳定的 DFS 模板？

直觉理解

二叉树 DFS 的核心，不是“怎么把树走完”，而是“每个节点到底在什么时候被处理”。递归把这件事拆得很自然：你站在某个节点上，只需要决定三件事：先处理自己、先去左边、还是先去右边。前序遍历是“先记下自己，再去左右子树”，适合在进入节点时就要做事；中序遍历是“先去左边，再记自己，再去右边”，适合把树按从小到大或结构顺序展开；后序遍历是“先把左右子树都处理完，最后再处理自己”，适合在需要先知道孩子结果、再汇总父节点结果的问题里使用。可以把递归想成一张张小任务单：每次只负责当前节点这一层，把更小的任务交给左右子树，最后由系统自动把结果一层层收回来。这样一来，树遍历不再是复杂的分支判断，而是一个统一的“走到哪、什么时候记录”的时机问题。掌握这个时机，就掌握了树题最基础的模板感。

算法思路

二叉树 DFS 遍历的第一步，是先建立一个最小递归框架：函数输入当前节点 `root`，如果节点为空就直接返回，因为空树没有可处理内容。然后围绕“访问时机”来定义三种遍历。前序遍历的顺序是“根-左-右”，所以在进入函数时就先记录当前节点值，再递归左子树，最后递归右子树。中序遍历的顺序是“左-根-右”，所以先递归左子树，回到当前节点时再记录值，最后递归右子树。后序遍历的顺序是“左-右-根”，所以必须等左右子树都递归结束后，才处理当前节点。这个框架本质上非常统一：不同遍历只是在“当前节点什么时候加入答案”上做了微调。 写题时可以把这个模板抽象成三段式：第一段是边界判断，第二段是进入左子树，第三段是进入右子树，中间插入一次“处理当前节点”的动作。前序把动作放在最前，中序把动作放在中间，后序把动作放在最后。这样做的好处是，你不需要为每种遍历重新发明逻辑，只要调整记录答案的位置即可。对于初学者来说，先用递归写出这三个版本，再把它们和“访问时机”对应起来，模板感就会很快建立。 为了让代码真正可用，建议把三种遍历都写成独立函数，返回列表结果。这样既便于对比顺序，也方便在面试或竞赛里直接套用。测试时可以用一棵简单树验证结果，例如 `1` 作为根，左子树 `2,4,5`，右子树 `3`，这样三种遍历的输出差异非常明显，能帮助你确认自己是否把“根节点记录时机”放对了位置。

Python 示例

from typing import Optional, List


class TreeNode:
    def __init__(self, val: int = 0, left: Optional['TreeNode'] = None, right: Optional['TreeNode'] = None):
        self.val = val
        self.left = left
        self.right = right


def preorder(root: Optional[TreeNode]) -> List[int]:
    """前序遍历：根 -> 左 -> 右"""
    ans: List[int] = []

    def dfs(node: Optional[TreeNode]) -> None:
        # 空节点直接返回，递归边界
        if node is None:
            return
        # 先处理当前节点
        ans.append(node.val)
        # 再递归左子树
        dfs(node.left)
        # 最后递归右子树
        dfs(node.right)

    dfs(root)
    return ans


def inorder(root: Optional[TreeNode]) -> List[int]:
    """中序遍历：左 -> 根 -> 右"""
    ans: List[int] = []

    def dfs(node: Optional[TreeNode]) -> None:
        if node is None:
            return
        # 先遍历左子树
        dfs(node.left)
        # 回到当前节点时再处理它
        ans.append(node.val)
        # 再遍历右子树
        dfs(node.right)

    dfs(root)
    return ans


def postorder(root: Optional[TreeNode]) -> List[int]:
    """后序遍历：左 -> 右 -> 根"""
    ans: List[int] = []

    def dfs(node: Optional[TreeNode]) -> None:
        if node is None:
            return
        # 先处理左子树
        dfs(node.left)
        # 再处理右子树
        dfs(node.right)
        # 两边都结束后，再处理当前节点
        ans.append(node.val)

    dfs(root)
    return ans


if __name__ == "__main__":
    # 构造一棵测试树：
    #         1
    #       /   \
    #      2     3
    #     / \
    #    4   5
    root = TreeNode(
        1,
        TreeNode(2, TreeNode(4), TreeNode(5)),
        TreeNode(3)
    )

    print("前序遍历:", preorder(root))   # [1, 2, 4, 5, 3]
    print("中序遍历:", inorder(root))    # [4, 2, 5, 1, 3]
    print("后序遍历:", postorder(root))  # [4, 5, 2, 3, 1]

    # 空树测试
    empty = None
    print("空树前序:", preorder(empty))
    print("空树中序:", inorder(empty))
    print("空树后序:", postorder(empty))

复杂度分析

三种遍历都只会访问每个节点一次，因此时间复杂度都是 `O(n)`，其中 `n` 是节点数。递归过程中，调用栈深度取决于树的高度 `h`，所以空间复杂度是 `O(h)`。如果树退化成链，最坏情况下空间复杂度会变成 `O(n)`；如果树比较平衡，通常是 `O(log n)`。

易错点

  1. 把前序、中序、后序的记录位置写错，比如把中序写成先 `append` 再递归，结果就会变成前序。修复方法是先记住三个顺序的核心口诀：前序是“根先记”，中序是“根居中”，后序是“根最后”。
  2. 忘记空节点返回，导致递归继续向下访问 `None.left` 或 `None.right`。修复方法是在递归函数开头统一写 `if node is None: return`，把边界处理放到最前面。
  3. 递归函数里误用共享变量或返回值混乱，比如一边 `return` 列表、一边又修改外部数组，最后结果重复或遗漏。修复方法是统一一种写法：要么所有结果都追加到外部 `ans`，要么每层返回子结果并合并，不要混用。
